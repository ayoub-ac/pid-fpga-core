## Notes

* The dominant area is the four parallel signed multipliers used for
  P (e * Kp), I (e * Ki*Ts), D (dpv * Kd/Ts) and back-calculation
  (excess * Kb). With default `GAIN_W = 32` and `Q_FRAC = 16` each
  multiplier is a 17-bit signed * 32-bit signed product (49-bit result).
  Yosys-generic synthesis maps this to LUT4 carry-chains. Vendor flows
  fold each multiplier into a single DSP block (DSP48 / DSP58 / M9K)
  and the LUT count drops sharply.
* The integrator accumulator is `ACC_W = 48` bits wide so a small
  Q15.16 `Ki*Ts` step (e.g. `0.001`) accumulates without rounding to
  zero across thousands of ticks.
* Pipeline depth is 4 cycles (capture, multiply, sum, saturate), so
  `f_max` on FPGA is expected to be gated by the multiplier path rather
  than by a long combinational chain through the saturate stage; not
  verified by timing analysis.
* Vivado / Quartus rows are skipped automatically when those tools are
  not on PATH; with WebPACK / Web Edition installed they are intended
  to be populated from a real synth_design / quartus_sh run. No CI
  workflow exists in this repository.
